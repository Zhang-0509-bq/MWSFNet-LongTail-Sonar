# Reproducibility notes

## What was verified

- **Observed locally.** The same 39 saved test runs and both ensembles are identified by result directory, ordered test identifiers, labels, seed and configuration. The verifier recomputes accuracy, G-mean, macro-F1 and per-class recall from the saved predictions, and sample standard deviations from the three seed values. It checks both ensembles from the members' float32 logits using float64 softmax and equal probability averaging. The replay agrees with the saved ensemble predictions and the values shown in the paper.
- **Split identity.** The release manifests keep dataset-relative names, original labels, row order, and the p0/k0 indices. NKSID training and validation partition the 2,094-image pool with a disjoint 523-image test set. FLSMDD training and validation partition the 1,650-image pool with a disjoint 714-image test set. The materialization script completed against both local dataset layouts. This establishes sample-list consistency for this paper. The nominal NKSID ratio alone cannot establish identity with the literature's split.
- **Static source audit.** The model and loss definitions were matched to two identical local working copies. The code has the published major components, including BAF's 3-to-8 and 4-to-8 projections, 32-to-16-to-4 gate, 748 gate parameters, and uniform initial branch weights. Locally archived run metadata records the intended flags; it does not identify the exact executed source files.
- **Local CPU smoke tests.** Imports, CLI help, the loader's four synthetic DWT/RGB inputs, 15-channel fusion and 4-channel comparison-model forwards, 8- and 10-class heads, initial gate weights, and the focal and logit-separation calculations passed. Torch 2.12.0+cpu, torchvision 0.27.0+cpu and PyWavelets 1.6.0 were used for the smoke tests. Fresh ResNet18 weights substituted for pretrained loading in this test. It does not exercise CUDA, historical weights, real-image model inference, or training.

## Known differences and limits

- **Frequency-aware initialization.** Equation (9) of the manuscript uses the mean magnitude of the already averaged base prior in the denominator. The local implementation scales the three-channel filtered tensor before averaging over RGB. These operations need not give the same weights. The Sobel mean kernel, subband assignment, and multiplicative perturbation match the high-level description. The archive does not identify the historical initialization path conclusively. The released source preserves the local calculation.
- **Loss naming.** The runs use `--loss focal`. Class balancing is implemented as inverse-frequency `N / (C * n_c)` and `gamma=2`; `--loss cb` is a different option. The source adds a tiny epsilon for numerical stability. Logit separation computes `sigmoid(max_wrong - true)`. With `e` counted from zero, the weights use `0.8 - 0.3 * e / E` and its complement.
- **Augmentation.** The recorded key `aug=none` selects the local default path, which still includes an RGB horizontal flip, same-size crop, and mild brightness/contrast jitter for training. Its DWT operates on the original grayscale image and standardizes each subband before bilinear resizing. The occupied flags and test sample identities are known. The archive does not establish historical transform execution or exact library behavior on the server.
- **Defaults.** The reference CLI's default `--es` is 100. Use the recorded `--es 80`. The archived `unfreeze_epoch` field is `10`, but the local copy only parses that argument. The presence of the field is insufficient to claim that freezing occurred during the paper experiments. Run artifacts document validation G-mean selection.
- **Archived summaries.** The older ensemble Markdown summaries contain an incorrectly labeled sym4 entry and incorrect BAF comparison deltas. This package uses the stored numeric run and ensemble records. `evaluation/ensemble_eval.py` is retained as the historical reference; its report generator mixes computed and reference rows under some label settings. Use `evaluation/verify_archived.py` for the included archive checks.
- **Historical provenance.** The local source includes working-tree edits relative to its last commit, among them the plain Wavelet-CNN path. The two local copies are byte-identical for the candidate files. No archived run binds the files to a server-side commit or dirty-tree snapshot. Python, PyTorch, torchvision, PyWavelets, CUDA, cuDNN, and the ImageNet pretrained weights used for each run have not been pinned. For proof of model-level reproducibility, the authors still need the exact server-side files and environment metadata tied to each experiment family.

## Release changes

Research model and loss operations were kept from the local source. The release changes point `config.py` at the repository's `data/`, omit the unused class-aware sampler and legacy pruning utility, remove unused imports, and defer plotting imports until plotting is requested. The training CLI help title and source whitespace were cleaned up. Two training helpers are copied from the historical analysis module into `paper_metrics.py`, so the full legacy analysis script is unnecessary. The path-preparation and archive-verification scripts were authored for this release. They use frozen split identities and numeric artifacts, and they do not participate in the recorded experiments.

`artifacts/*.npz` repackages the archived logits, integer predictions, and labels with dataset-relative sample IDs. Each archive is covered by a checksum in `configs/canonical.json`. Checkpoints, third-party images, raw run logs, development and server configuration, and R1 or Phase C materials are outside this release. The source snapshot and model-level verification can be supplied separately after the authors establish provenance and redistribution permissions.
